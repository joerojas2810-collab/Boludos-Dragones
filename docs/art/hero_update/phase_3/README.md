# Phase 3 — Pixel Assassin

Approved by Felipe on 2026-10-09 as part of closing phases 3 and 4. The adult female Assassin replaces the rogue appearance while keeping existing class and file identifiers.

Ten actions and five elements, 36 frames per element. Source frames are 128×192 with feet at (64,180); runtime PNG frames include six transparent columns on either side, yielding 140×192 and feet at (70,180). Final runtime files are in public/art/heroes-px. Element masks use the source frame layout. Animated poses use limited pixel-aligned motion, not skeletal animation.

The other three pixel hero classes retain their original assets. Original atlas, generation prompts and enlarged exports remain in the local delivery and are excluded from this repository.
